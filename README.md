# Cartera Local | PCAM - LAB001

Cartera virtual de paper trading (USD 5.000 desde el 11/11/2026), operada desde Argentina vía BYMA y medida en USD MEP.

Este repositorio va a contener:

- el registro de la cartera (posiciones y operaciones),
- el programa que actualiza los precios y la valuación todos los días después del cierre,
- el tablero web con los resultados.

No contiene contraseñas, claves ni conexión con ningún broker. Es un test.
